# 教室借用申请 · 填表指南（必读）

> 本知识库由 **agent 自动维护**。请只在自己的申请文档里填写，
> **不要新建 / 删除 / 移动目录，不要改动本指导文档**。
> 不符合规范的文档会被 agent 自动移动或删除。

---

## 一、提交一份申请（3 步）

1. 打开**当前有效**的申请目录，例如 **`0914-0920`**（表示 9 月 14 日 ~ 9 月 20 日）。
2. 在该目录下 **新建文档**，标题按 `姓名-日期-节次` 格式，例如：`张三-0916-7-8节`。
3. 把《教室申请模板》的全文复制进来 → 逐项填好 → 把第一行改成 **`状态：待提交`** → 发布。

> ⚠️ 只有 `状态：待提交` 的文档才会被 agent 处理。

---

## 二、申请文档模板（字段名不允许改动）

```markdown
状态：草稿

活动名称：
申请人：
真实姓名：
联系方式：
活动日期：
使用节次：
预计人数：
意向教室或教学楼：
活动简介：
```

| 字段 | 要求 | 示例 |
|---|---|---|
| 状态 | 提交前改为 `待提交` | `状态：待提交` |
| 活动名称 | 必填，简短 | `新生见面会` |
| 申请人 | 必填，你的语雀昵称 | `张三` |
| 真实姓名 | 必填 | `张三` |
| 联系方式 | 必填，手机号 | `13800000000` |
| 活动日期 | 必填，`YYYY-MM-DD`，可带星期 | `2026-09-16（周三）` |
| 使用节次 | 必填，`起-止`，取值 1~12 | `7-8` |
| 预计人数 | 必填，正整数 | `30` |
| 意向教室或教学楼 | 必填，可写「随意」 | `仙林 仙II区` |
| 活动简介 | 可选，一句话 | `社团分享会` |

---

## 三、状态机（agent 会改写你文档首行的「状态」）

| 状态 | 谁写 | 含义 |
|---|---|---|
| `草稿` | 你 | agent 直接忽略 |
| `待提交` | 你 | 交给 agent 校验 |
| `已退回（修改后请把状态改为待提交）` | **agent** | 校验不通过，请按审批日志的意见修改，**改完把状态改回 `待提交`** |
| `已提交（待审核通过）` | **agent** | 校验通过，已提交学校系统，等待审核 |
| `已通过（本文档已归档，禁止再次修改）` | **agent** | 学校审核通过，本申请已结束 |

> 状态被 agent 改过之后，**不要手动改成别的值**；要重新提交就把状态改成 `待提交`。
> 「已通过」之后请不要再修改本文档——虽然语雀没有强制锁定，但 agent 会以审核时的版本为准。

---

## 四、agent 的校验规则

1. 状态必须是 `待提交`；
2. 上表**必填项不能为空**；
3. **活动开始时间距提交时刻必须 ≥ 48 小时**（活动开始时间 = 日期 + 该节次起始时刻）；
4. **节次**必须是 1~12 的整数或 `起-止` 范围，且起 ≤ 止；
5. **人数**必须是正整数；
6. 文档必须放在**对应的申请目录**下（放错位置但能识别时，agent 自动移动）。

---

## 五、agent 会做什么

1. 读取知识库里的所有文档；
2. **合规** → 把状态改为 `已提交（待审核通过）`，并在你的文档下维护子文档 **`审批日志`**；
3. **不合规** → 把状态改为 `已退回（修改后请把状态改为待提交）`，
   在 `审批日志` 里写明原因（并用评论 @ 你，如果 agent 有评论权限）；
4. **放错位置但能识别** → 自动移动到正确的周目录；
5. **无法识别**（未使用模板、不是申请文档、空文档、标题为「无标题文档」等）→ **直接删除**；
6. 过期的周目录会被整体移动到 **`归档区`**，归档后不再处理。

> `审批日志` 由 agent 自动维护，**请勿手动编辑**。

## 七、时间窗口与归档

- 申请**只接受当前周与下一周**的教室；过期的周目录由 agent 移入 `归档区`。
- `归档区` 内的文档**不再处理**；如需重新申请，请在当前有效目录下新建一份。
- 一次活动一份文档；多场活动请分别提交。
